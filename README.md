# Star Barbershop Günzburg

Eine responsive, deutsch-englische Website für Star Barbershop.

## Dateien

- index.html: komplette Seite, eingebettete Bilder und Sprachumschaltung
- style.css: Gestaltung und mobile Darstellung
- index.php: optionaler Einstieg für PHP-Hosting; lädt index.html aus demselben Ordner

Die drei Dateien müssen im selben Ordner bleiben.

## Vorschau

index.html in einem Browser öffnen.

## Veröffentlichung

Für statisches Hosting index.html und style.css verwenden. PHP benötigt einen PHP-fähigen Webhost. GitHub Pages führt PHP nicht aus.

Vor dem öffentlichen Geschäftsbetrieb die noch als Entwurf markierten Hosting- und Unternehmensangaben in Impressum und Datenschutz vervollständigen.
